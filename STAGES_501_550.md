# Stages 501-550 — Arabic Product Advertisement Workflow

## Objective

Create a product advertisement without requiring prompt engineering or manual video-editing commands.

The normal input is:

- Product photos.
- Product name and/or model.
- Selling price and currency.
- Optional factual description / selling points.
- Optional phone or contact text.

The output workflow is:

Product facts → deterministic Arabic script → portrait advertising frames → Arabic voiceover → MoneyPrinterTurbo local-material video → MP4.

## Factuality rule

The script generator does not invent specifications, warranty, performance claims, origin, discounts, or features. It only reformulates the fields supplied by the user plus generic non-factual advertising transitions and call-to-action language.

If the supplied facts do not contain enough words for the requested 60-second target, the GUI reports the estimated narration length instead of hallucinating padding.

## Arabic voice

- Default: ar-EG-SalmaNeural.
- Alternative: ar-EG-ShakirNeural.
- These are Edge TTS voice identifiers listed by the reviewed MoneyPrinterTurbo source.
- Edge TTS is free/no-key but requires network access to the speech service.

## Image preparation

Selected images are explicitly imported by the user, validated, and copied into the approved workspace. Each image is rendered to 1080x1920 with:

- blurred/darkened image background,
- metallic-silver content frame,
- full product image fitted into the layout,
- neon product name,
- model,
- neon-green price.

Up to 12 images are accepted. Invalid or oversized input is rejected before rendering.

## Video rendering

The Product Ad Creator:

- auto-prepares the reviewed MoneyPrinterTurbo checkout if needed,
- uses local material mode so product photos remain the source material,
- supplies the generated Arabic script directly, skipping LLM script generation,
- uses sequential image order,
- uses fade transitions,
- provides optional local random background music,
- keeps the output portrait at 9:16.

Arabic subtitles are disabled in this first verified ad profile because the reviewed MoneyPrinterTurbo bundled fonts are not Arabic-specific. The product/model/price remain visible in the composed frames and the narration is Arabic.

## Release requirements

The Product Ad window is part of Navigation Integrity Probe. Stage 550 requires Windows and Ubuntu CI, runtime UI probe, navigation probe, security scans, dependency audit, native executables, Windows installer smoke, and Debian package smoke.
