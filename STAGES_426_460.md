# Stages 426-460 — Information, Security and Navigation Integrity

## 426-435 — About / عنا

- Always-visible information navigation below the main NEXVARY header.
- Dedicated About / عنا window with official NEXVARY identity.
- Official Website, Facebook, Email, YouTube, and X buttons.
- Explicit Back / رجوع control.
- Social links are user-invoked only; automated UI probes do not open them.

## 436-445 — System Overview / حول النظام

- Dedicated System Overview / حول النظام window.
- Documents Easy Mode, agent orchestration, persistence, build/release, UI QA, security,
  desktop/browser automation, media/MCP, Android/GitHub, and Advanced Mode.
- Includes a verification statement distinguishing "no findings in configured checks"
  from an impossible guarantee of zero future vulnerabilities.

## 446-454 — Navigation Integrity Probe

- Opens Easy Mode and Advanced Mode.
- Opens About and System Overview.
- Opens Add Project.
- Iterates every built-in Tools & Integrations subpage.
- Iterates every Tool Box category.
- Checks geometry, overlap, interactive target size, and missing button callbacks on each window.
- Audits every public DeveloperAgentUI method beginning with open_ so newly added pages cannot
  silently escape the route registry.
- Stores source-fingerprinted evidence in project state.

## 455-460 — Security and Release Gate

- Release policy requires navigation evidence for NEXVARY's desktop UI.
- Strict Release Gate rejects stale or failed Navigation Integrity evidence.
- CI runs pip-audit against declared runtime/UI-test dependencies.
- Existing secret scan, Python AST audit, workspace health, runtime UI probe, packaging smoke,
  and installer smoke tests remain active.

Stage 460 is accepted only when the exact branch head passes Windows and Ubuntu CI.
