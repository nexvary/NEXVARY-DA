# Stages 461-500 — Local Video Studio

## Goal

Make one-minute video creation a normal graphical workflow rather than a collection of CLI commands.

## 461-480 — Engine manager

Three optional MIT-licensed engines are registered with immutable reviewed commits:

1. MoneyPrinterTurbo — primary mature short-video pipeline.
2. Automated Video Generator — preferred keyless/free self-hosted fallback.
3. ShortsGenerator — alternative local Shorts pipeline with local TTS and subtitle templates.

The manager discovers prerequisites, prepares engine checkouts under the approved workspace, pins the reviewed commit, installs dependencies, launches local WebUIs through the managed process registry, and never persists provider API keys.

## 481-495 — Graphical Video Studio

- Easy Mode exposes Video Studio directly.
- Default profile: 60 seconds, 9:16 portrait, Arabic, MoneyPrinterTurbo.
- Topic or full-script input.
- Duration presets: 30 / 45 / 60 / 90 seconds.
- Aspect ratio: 9:16 / 16:9 / 1:1.
- Arabic and English language presets.
- Pexels, Pixabay, Coverr, or local visual material selection for MoneyPrinterTurbo.
- Local video/image file picker.
- Optional engine voice id.
- One-click PREPARE, START, OPEN and CREATE VIDEO actions.
- Automated Video Generator and ShortsGenerator open their own local graphical creators after setup.
- Long-running setup/render jobs run on worker threads so the NEXVARY window stays responsive.

## 496-500 — Verification and release requirements

- Video Studio is included in Navigation Integrity Probe.
- Engine registry and default profile have unit tests.
- External source is not vendored into NEXVARY-DA.
- Third-party notices record repository, MIT license, and reviewed commit.
- Stage 500 requires the exact branch head to pass Windows and Ubuntu CI, security source/secret scan, dependency audit, runtime UI probe, Navigation Integrity Probe, native builds, and package installer smoke tests.
