# Stages 401-425 — Neon Chrome Visual System

This milestone is a visual/interaction refinement over the verified Stage 400 usability baseline.

## 401-407 — Chrome frame system

- Deep black/navy application chassis.
- Metallic-silver borders on cards, panes, headers, entries, and action surfaces.
- Bright silver focus treatment to create a chrome-like edge without image assets.
- A thin electric spectrum rail under the main header.

## 408-414 — Neon spectrum semantics

- Cyan: primary NEXVARY identity, task/project and MCP accents.
- Electric blue: build/desktop.
- Purple: browser/tools.
- Magenta: image/media.
- Orange: video/release.
- Yellow/gold: voice/project highlights.
- Red remains failure/danger.
- Green is reserved for buttons and press/action affordances.

## 415-420 — Action language

- Primary press targets use neon-green fill.
- Secondary buttons use green text on dark surfaces with silver borders.
- Hover/active state brightens the green so clickable controls are obvious.
- PASS/READY state uses cyan instead of green to prevent semantic collision with buttons.

## 421-425 — Easy Mode visual hierarchy

- Each Easy Mode card gets a different neon top rail while retaining a consistent silver frame.
- Setup Center and Tool Box inherit the same chrome/neon language.
- Entry fields receive silver borders and neon focus/caret treatment.
- Runtime UI probe and cross-platform packaging remain release acceptance requirements.
